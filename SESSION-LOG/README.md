# SESSION-LOG/

One log file per session. Written at the end of every session before committing.

## Naming convention

```
YYYY-MM-DD-SNN-description.md
```

Examples:
- `2026-04-11-S01-phase0-scaffold-keel-deck.md`
- `2026-04-14-S03-phase1-m1-matters-schema-keel.md`

## Status

| Session | Date | Description |
|---|---|---|
| S01 | — | Phase 0 scaffold — not yet started |
| S02 | — | Phase 0 scaffold continued — not yet started |

## Rules

- Copy TEMPLATE.md for every new session log.
- Fill every section — do not leave placeholders.
- A session without a log is an incomplete session.
- Append the session to the Session Log table in PROGRESS.md.
