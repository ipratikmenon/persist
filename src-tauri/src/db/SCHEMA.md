**Status transition rules (enforced in Keel, not at DB level):**

```
Active              → OnHold, PendingClientResponse, Closed, Archived

PendingClientResponse → Active, Closed, Archived
Closed              → Archived
Archived            → (terminal — no transitions out)
```

**Urgency tiers (calculated from `due_date` for Pending deadlines):**

| Tier | Condition |
|---|---|

### `documents`

Encrypted document metadata. File bytes live in the vault (`src-tauri/storage/vault.rs`).
NEVER store raw bytes in this table.

| Column | Type | Notes |
|---|---|---|
| `id` | TEXT PK | UUID |
| `matter_id` | TEXT NOT NULL | FK → `matters(id)` ON DELETE CASCADE |
| `filename` | TEXT NOT NULL | Original filename shown to users |
| `category` | TEXT NOT NULL DEFAULT 'Other' | `Correspondence \| Filing \| Certificate \| SearchReport \| Invoice \| Contract \| Other` |
| `mime_type` | TEXT NOT NULL DEFAULT 'application/octet-stream' | |
| `file_size_bytes` | INTEGER NOT NULL DEFAULT 0 | Size of the plaintext original |
| `version` | INTEGER NOT NULL DEFAULT 1 | Incremented on re-upload of same logical document |
| `vault_path` | TEXT NOT NULL | Vault-relative path to the `.enc` file — NEVER sent to Deck |
| `uploaded_by` | TEXT NOT NULL DEFAULT 'system' | Soft FK → users(id) — enforced after auth migration |
| `is_shared_with_client` | INTEGER NOT NULL DEFAULT 0 | 1 = visible in client portal |
| `description` | TEXT | Optional user note |
| `created_at` | DATETIME NOT NULL DEFAULT (datetime('now')) | |
| `updated_at` | DATETIME NOT NULL DEFAULT (datetime('now')) | |

**Vault file format:**
```
{vault_dir}/{matter_id}/{doc_id}.enc
= [12-byte random nonce][AES-256-GCM ciphertext + 16-byte auth tag]
```

**Security invariants:**
- `vault_path` is NEVER serialised to Deck — the `DocumentMeta` IPC type intentionally omits it
- Every byte returned to clients goes through `clean_metadata()` before dispatch
- `vault_key` is a placeholder `[0u8; 32]` until Phase 1 Auth loads the real key from the OS keychain

**Indexes:** `idx_documents_matter`, `idx_documents_category`, `idx_documents_created`

## Conventions

- All IDs are `TEXT PRIMARY KEY` (UUID via `uuid::Uuid::new_v4().to_string()`)
- Matter IDs follow the format `P&P-YYYY-TYPE-NNNN` — generated by Keel, never Deck
- All timestamps: `DATETIME NOT NULL DEFAULT (datetime('now'))`
- Soft deletes only — no hard deletes for matters, clients, or documents
- snake_case for all table and column names
- JSON arrays stored as `TEXT DEFAULT '[]'`
- Booleans stored as `INTEGER` (0/1)
