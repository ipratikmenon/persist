# Persist — Module 04: Time Tracking & Billing
**Phase:** 2
**Status:** Spec approved — ready for implementation
**Last updated:** 2026-04-15

---

## 1. Purpose

Enable Persistas & Partners to track billable time against matters, generate GST-compliant tax invoices in INR, and record client payments. Everything runs local-first on the desktop — invoices are generated via a bundled LaTeX template into PDFs, stored in the vault, and optionally shared with the client portal.

---

## 2. Users & Roles

| Role | Can do |
|---|---|
| Partner | All: create/edit/delete time entries, generate invoices, record payments, set billing rates |
| Associate | Create own time entries, view own invoices, cannot generate invoices or set rates |
| Paralegal | Create own time entries only |
| Admin | All billing operations |

## 3. Core Concepts

### 3.1 Time Entries

An attorney records time spent on a matter. Key fields:
- `matter_id` — which matter
- `user_id` — which attorney billed this time
- `date` — date of work (DATE, not DATETIME)
- `hours` — decimal hours (e.g. 2.5 = 2 hours 30 minutes), minimum 0.25
- `description` — what was done (max 500 chars)
- `activity_code` — standard activity code (see §3.4)
- `rate_per_hour` — INR per hour at time of entry (snapshot, not live)
- `is_billable` — 1 = billable, 0 = non-billable (internal time)
- `is_invoiced` — 1 = included in an issued invoice (prevents double-billing)
- `invoice_id` — NULL until invoiced

### 3.2 Invoices

A formal GST tax invoice for a client, covering one or more matters and time entries.

**Invoice ID format:** `INV-YYYY-NNNN` (e.g. `INV-2026-0001`)
Sequenced separately from Matter IDs using the `sequences` table (key: `INV-{YEAR}`).

**Invoice states:**
```
Draft → Sent → Paid (full or partial) → Cancelled
Draft → Cancelled
```

**GST treatment (Indian legal services):**
- SAC code: 998212 (legal advisory and representation)
- Intra-state (Delhi client): CGST 9% + SGST 9% = 18% total
- Inter-state (outside Delhi client): IGST 18%
- Firm GSTIN: stored in `firm_settings` table

### 3.3 Payments

Partial or full payments against an invoice. An invoice is fully paid when `SUM(payments.amount) >= invoice.total_with_tax`.

### 3.4 Activity Codes

Standard codes used in the legal billing industry (LEDES-inspired, simplified for Indian IP):

| Code | Description |
|---|---|
| `L100` | Case assessment / consultation |
| `L200` | Research |
| `L300` | Drafting / preparation |
| `L400` | Filing / prosecution |
| `L500` | Review / analysis |
| `L600` | Court / hearing attendance |
| `L700` | Client communication |
| `L800` | Administrative / coordination |
| `L900` | Travel |

## 6. LaTeX Invoice Template

Location: `src-tauri/storage/templates/invoice.tex`

**Template variables (double-brace syntax):**
```
{{INVOICE_ID}}          {{INVOICE_DATE}}       {{DUE_DATE}}
{{FIRM_NAME}}           {{FIRM_GSTIN}}         {{FIRM_ADDRESS}}
{{FIRM_PAN}}            {{FIRM_BANK}}          {{FIRM_IFSC}}
{{CLIENT_NAME}}         {{CLIENT_GSTIN}}       {{CLIENT_ADDRESS}}
{{LINE_ITEMS_TABLE}}    — injected as LaTeX tabular rows
{{SUBTOTAL}}            {{CGST_LABEL}}         {{CGST_AMOUNT}}
{{SGST_LABEL}}          {{SGST_AMOUNT}}        {{IGST_LABEL}}
{{IGST_AMOUNT}}         {{TOTAL}}              {{AMOUNT_IN_WORDS}}
{{NOTES}}               {{SAC_CODE}}
```

**Amount in words:** Generate Indian-style amount in words (e.g. "Rupees Fifteen Thousand Four Hundred and Forty Only") — implemented in Keel.

**GST layout:**
- Intra-state: Show CGST row + SGST row (no IGST row)
- Inter-state: Show IGST row only (no CGST/SGST rows)

## 10. Constraints & Rules

1. **Immutable invoiced time entries** — `is_invoiced = 1` entries cannot be edited or deleted. Surface a clear error in Deck.
2. **GST calculation** — always computed in Keel, never in Deck. Deck only displays the values.
3. **PDF generation** — async, Tauri progress notification while latex.rs subprocess runs. PDF bytes go into the vault; `pdf_doc_id` is set on the invoice row.
4. **Rate snapshots** — `rate_per_hour` is copied from `firm_settings` at time of entry creation. Changing firm rates does not retroactively change existing entries.
5. **Minimum hours** — 0.25 enforced in Keel; reject anything smaller with an error.
6. **Invoice PDF filename** — `{invoice_id}-{client_name}.pdf` (sanitised for filesystem).
7. **Amount in words** — Indian style, INR only, using the `num2words` crate or hand-rolled for INR.
8. **Partner-only settings** — `update_firm_settings` returns an error if called by Associate/Paralegal.
9. **Cancellation** — Cancelled invoices unset `is_invoiced` on all linked time entries, making them billable again.
10. **Overdue** — An invoice is overdue if `status = 'Sent'` and `due_date < today`. Calculated at query time, not stored.
